## About me

I am a software engineer based in Lahore, Pakistan. I build user-facing applications, backend services, APIs, and AI-assisted communication workflows. My main stack is TypeScript with React, Vue, and Node.js, supported by PostgreSQL, Prisma, Redis, queues, testing, and containerized deployments.

My recent work includes production voice and SMS automation, API integrations, multi-tenant application safeguards, billing reliability, background jobs, and production debugging. I enjoy turning unclear requirements into small, reviewable releases that are easy to operate and maintain.
